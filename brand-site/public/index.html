Why Brandname

Tools that run next to your games shouldn't cost you frames.

Light on your PC

Native apps built in Rust, not a web browser in disguise. Echo uses about 150 MB of memory while recording; Medal uses around 470 MB.

Free, no catch

No ads, no tracking and no paid version of the apps. Echo's optional cloud storage has paid plans for people who want more space.

Open source

The code is on GitHub under the GPL-3.0 licence, so anyone can check what the apps do or build them.

Windows & Linux

Windows 10 and 11, and Linux, including Steam Deck and Bazzite through Flatpak.
