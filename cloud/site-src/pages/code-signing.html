Code signing policy

Last updated: 4 November 2026

Echo's Windows downloads (Echo-Setup.exe and Echo.exe) are built from the public source code by GitHub Actions and are meant to be signed through the SignPath Foundation's free code signing for open-source projects (application in progress). Until that's in place, Windows may show a SmartScreen warning when you start the installer.

Once approved: Free code signing provided by SignPath.io, certificate by SignPath Foundation.

What gets signed

  • Only files built from the public repository github.com/Resister0/echoclip by its GitHub Actions workflow. Every release on GitHub shows the exact commit it was built from.
  • Echo's own program files (the installer and Echo.exe). Third-party tools that come with Echo - FFmpeg, rclone - are the unchanged official builds from their own projects and keep their authors' signatures, if they have any.
  • Nothing is signed by hand on a personal computer.

Everyone with access uses two-factor authentication on GitHub and SignPath. Outside contributions are reviewed before they are merged.

Privacy

Echo does not send any data to other computers unless you ask it to, with one exception: an installed Echo checks echoclip.link every few hours for a newer version. That check contains only Echo's version number and your system type (Windows or Linux).

Everything else happens only when you choose it: connecting a cloud (Echo Cloud, Google Drive or your own storage), making a share link, sending feedback or sending a log. The full details are in the privacy policy, which the Windows installer also links to.

Reporting a problem

If you think a signed Echo file was tampered with or behaves maliciously, email support@echoclip.link. Signing certificates can be revoked by SignPath if this policy is broken.
