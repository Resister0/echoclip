Installing

Windows

Run Echo-Setup.exe. If Windows says "Windows protected your PC", click More info → Run anyway - Echo isn't code-signed yet, so SmartScreen doesn't know it.

Linux

Make the AppImage runnable (right-click → Properties → "Allow executing", or chmod +x Echo-x86_64.AppImage) and open it. Echo uses gpu-screen-recorder and ffmpeg from your system.

First start

A short setup picks your hotkey and where clips go. Then play - press the key whenever something happens worth keeping.

What you need

Windows

Windows 10 (1903 or newer) or 11, 64-bit, and a graphics card with a video encoder - practically every NVIDIA, AMD or Intel GPU from the last eight years.

Linux

A current 64-bit distribution with gpu-screen-recorder and ffmpeg installed.

Disk space

About 12 MB for Echo, plus roughly 1.5 GB for a 10-minute replay buffer at the standard quality.
