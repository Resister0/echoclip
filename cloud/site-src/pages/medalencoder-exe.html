What is MedalEncoder.exe?

It's the part of Medal, the game clip app, that records your screen and encodes the video. If it uses a lot of CPU, it's almost always a setting in Medal, and a few changes bring it down.

How to lower it A lighter recorder

What it does

Medal's recorder

Medal keeps the last minutes of your game ready so you can save a clip with one key. That recording and the video encoding run in their own process: MedalEncoder.exe.

Why Medal shows 0 %

Because the encoder is a separate process, Medal's own row in Task Manager can show almost nothing while MedalEncoder.exe does the work. Look at both to see what Medal really uses.

Is it safe?

Yes, when Medal is installed: it's a normal part of the app. If you never installed Medal, right-click it in Task Manager → Open file location and check where it lives.

Why it can use a lot of CPU

The encoder is set to CPU

Medal can encode with your graphics card or with the processor. On the processor ("libx" in Medal's list) every frame is compressed by the CPU, which costs the most.

High quality settings

A higher resolution, frame rate or bitrate means more work for every second of the replay buffer.

Auto Clipping

Medal's support pages call Auto Clipping experimental and say it needs more resources while it's on.

How to lower it in Medal

  1. Open Task Manager while Medal records and look at CPU and GPU for MedalEncoder.exe.
  2. CPU high? In Medal: Settings → Clip Settings → Video Encoder, pick your graphics card (NVIDIA, AMD or Intel) instead of "libx".
  3. GPU busy instead? Medal suggests the opposite there: switch to "libx" for that game.
  4. Lower the quality a step (resolution or bitrate) if it's still high.
  5. Turn off Auto Clipping if you don't use it.
  6. Update your graphics driver.

From Medal's own support pages, checked 26 November 2026. Menu names can change with Medal updates. Medal is a trademark of its owner; Echo isn't connected to it.
