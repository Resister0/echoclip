# Echo icons (logo from 12 Nov 2026)

Two colours of the same logo (replay ring + arrow + play, glass finish):

- **echo-dark-*** - the app: taskbar, tray, window, installer, Discord. Same as `prototype-native/echo.ico`.
- **echo-violet-*** - the web: echoclip.link, sonela.app, listings (SourceForge, AlternativeTo, GitHub).

Sizes 16-1024 px as PNG, plus `.ico` (Windows) and `.svg` (the master; `-small.svg` is the flat, crisp cut used at 32 px and below).
